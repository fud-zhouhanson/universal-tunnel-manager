通用隧道管理器

识别本机由 VPN / 游戏加速器 / 代理 / 覆盖网络 建立的隧道， 按域名把流量在「隧道」与「本机直连」之间切换。不改客户端、不卸载软件、随时回滚。

macOS

运行后自动打开浏览器 http://127.0.0.1:7531（仅监听本机，同一内网的其他设备访问不到）。 桌面会生成「隧道管理」图标，之后双击它即可打开。

3启动失败时：用包内的体检工具

体检工具就在解压出的文件夹里，与启动文件并排： 

Windows → 双击  检查运行.bat
macOS   → 双击  检查运行.command

它会逐项检查运行环境，并在同一文件夹内生成「检查报告.txt」—— 把该文件提供给维护者即可定位问题。

  • 检查是只读操作：不改路由、不动 DNS、不安装任何东西
  • 报告只含系统版本、网卡名、路由状态，不含任何隐私内容
  • macOS 首次运行可能提示「无法验证开发者」：在该文件上右键 →「打开」放行一次即可

4打开后可以看到

程序仅监听本机 http://127.0.0.1:7531，并自动打开浏览器。 同一内网的其他设备访问不到该地址，仅本机可用。

  • 检测到的隧道软件 — 哪些在运行、各属哪一类
  • 网络接口与隧道归属 — 每块网卡是隧道还是物理网卡、归属哪个软件（含 MTU / IPv6 ULA 指纹）
  • 聚合路由多点抽查 — 检出「保留默认路由、改用聚合路由接管」的隐性隧道
  • 目标域名的路由走向 — 指定域名的流量当前从哪个接口出去
  • 真实流量体检 — 不看配置只看事实：真解析一次、真连一次、真看第一跳
  • 应急恢复 — DNS 与路由被改动后一键还原
  • 一键切换 — 切到本机直连 / 交回隧道；「待确认」项可一键取消

5实现方式

识别进程证据 + 网卡名证据 + 路由出口证据 + ULA/MTU 指纹，四层融合判定隧道归属
切换给目标 IP 加一条比默认路由更具体的 /32 主机路由，指回物理网关，不影响其他流量
回滚每条添加过的路由都记入 state 文件，撤销时只删自己加的，不触碰系统原有路由
安全仅绑定 127.0.0.1；写操作校验 Origin + CSRF token；只对公网 IP 加路由，防 DNS 投毒
通用隧道管理器 · 单文件 Python 程序，不写入系统目录以外的任何位置
卸载：删除解压出的文件夹即可（Windows 免安装版不写注册表、不注册服务）
